# 无轨迹基线 kill test：结果报告

日期：2026-08-31  
绑定状态：**`NO_GO_ENGINEERING`**

## 结论先行

本轮得到一个强但尚未获准晋级的信号：对于本来能够独立做对的 GSM8K
题目，纠错器看到同谱系错误轨迹后，比看到跨谱系错误轨迹多产生 **18.55 个
百分点**的新错误；95% 题目聚类 bootstrap 区间为 **[11.69, 25.53]** 个百分点。
它保留原始错误答案的概率也高 **20.56 个百分点**，区间为 **[13.76, 27.34]**。

但是冻结协议先检查工程质量。240 个无轨迹回答中有 5 个达到 768-token 上限，
质量失败率为 **2.083%**，比预注册的 2% 上限多 1 个样本。因此自动门必须返回
`NO_GO_ENGINEERING`，不能在看到强效应后把阈值改成 2.1%、删除样本或追认晋级。

这不是“机制已经被否定”，也不是“实验通过”。准确表述是：**信号足够强，值得
重新设计一个全新、干净、跨提供商的确认实验；本轮本身不授权进入下一阶段。**

## 冻结设计

- 使用父实验完全相同的 4 个模型修订：Qwen2.5 3B/7B、Qwen3 4B/8B；
- 使用父实验完全相同的 60 个共同 GSM8K 问题；
- 每个纠错器在不看到任何候选解答时独立求解一次，共 240 次调用；
- greedy decoding、FP16、768 新 token 上限；
- 结果出现前冻结问题集、模型修订、提示、哈希、估计量、bootstrap 和自动门；
- 主分析只保留“该纠错器无轨迹时能独立做对”的纠错器—问题对，然后测量错误轨迹
  暴露造成的新损害；
- 10,000 次按题目聚类 bootstrap，seed 20260830。

## 额外诊断（非绑定）

外部角色下的同谱系额外损害并非四个模型完全均匀：

- Qwen2.5-3B：0.00 pp；
- Qwen2.5-7B：+11.43 pp；
- Qwen3-4B：+23.44 pp；
- Qwen3-8B：+34.85 pp。

assistant-history 下四个模型均为正方向。总体信号主要由 Qwen3 纠错器贡献，因此当前
数据仍可能反映 Qwen2.5 与 Qwen3 的特定训练谱系差异，而不是普遍规律。

## 能说与不能说

可以说：

1. 共享盲点不足以轻易解释全部现象，因为分析限定在纠错器无轨迹时能做对的题；
2. 同谱系错误不仅降低正确率，还更容易把具体源错误答案保留下来；
3. 效应在外部角色中存在，因此不只是 assistant-history ownership 标签造成的；
4. 该现象是值得进行新确认实验的异常源。

不能说：

1. 当前实验已经通过自动门；
2. 已经发现跨提供商或普遍的“同类错误传染定律”；
3. 模型识别了来源身份；熟悉度、答案锚定、共享启发式仍是竞争解释；
4. 已经达到 ICLR Oral 的贡献深度；
5. 可以通过放宽 2% 阈值、删除五个触顶样本或只汇报后续门来晋级。

## 下一步约束

不能原样补跑或扩大当前同提供商网格。一个合格的新实验至少需要：

1. 全新预注册、简洁输出格式，并对无轨迹和所有暴露条件使用一致预算；
2. 至少一个真正跨提供商的谱系复制；
3. 将错误的最终答案与错误推理分别干预；
4. 对轨迹做语义保持的风格中和/风格迁移，以区分文本熟悉度与语义错误吸引；
5. 保持外部角色字节级对照，并加入无轨迹独立求解基线；
6. 只有在内容效应跨风格、跨角色、跨提供商存在时，才讨论内部机制或部署方法。
