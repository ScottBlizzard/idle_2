# 接收者原生错误增益：空白布局因果 Kill Test 报告

## 绑定结论

最终判定为 **`KILL_NO_CAUSAL_ERROR_GAIN`**。

本实验成功地只靠自然空白与分段方式改变了错误轨迹在接收模型下的 NLL，同时严格保持所有非空白字符、字符顺序、计算内容和错误答案不变；但这种干预没有稳定改变接收模型保留源错误答案的概率。

因此，前一阶段发现的“低 NLL 轨迹更容易传播错误”目前应解释为一个强**预测标记**，而不是已经证明的表面原生性因果旋钮。

## 完整性与工程质量

- 候选库：30 道 hash 选定的 GSM8K 问题、120 条错误轨迹、1337 个唯一布局版本。
- 每条轨迹唯一候选数：最少 6、最多 12；预注册最低要求为 4。
- 候选似然：4 个接收模型各 1337/1337，共 5348 个评分单元。
- 自动选择：480/480 个 trace-receiver 单元均找到 token 数差不超过 2 的高/低原生配对。
- 配对纠错：4 个接收模型各 240/240，共 960 个生成结果。
- 完整远端运行包：31 个文件；本地与远端 SHA-256 为 31/31 一致，0 个不匹配。
- 解析或达到 1024-token 上限：6/960，失败率 `0.625%`，通过 `2%` 工程门槛。

这次科学 NO-GO 不是显存、SSH、解析器或截断造成的。

## 主要结果

### 源错误答案保留（主指标）

`high_native − low_native = +0.00625`

问题聚类 95% CI：`[−0.01875, +0.03333]`。

门槛要求至少 `+0.08` 且区间严格高于 0；实际点估计只有 0.625 个百分点。

按接收模型：

- Qwen2.5-3B：`+0.01667`
- Qwen2.5-7B：`−0.01667`
- Qwen3-4B：`0.00000`
- Qwen3-8B：`+0.02500`

只有两个模型为正，低于预注册的三模型方向一致要求。

### 正确率（次指标）

`high_native − low_native = −0.01250`

问题聚类 95% CI：`[−0.03750, +0.01250]`。

四模型分别为 `−0.00833`、`−0.02500`、`+0.01667`、`−0.03333`。没有证据表明高原生布局提高或降低了纠错正确率。

### 为什么连续 NLL 仍显著？

预注册的 problem/corrector/generator 控制二项模型仍给出 NLL 系数 `−0.6665`，95% CI `[−0.9372, −0.3959]`。这与此前诊断一致：在不同错误轨迹之间，低 NLL 文本确实更容易伴随源错误保留。

但这个模型没有控制每一条源错误轨迹自身。真正的 paired intervention 已经固定源轨迹，只比较同一轨迹的两个布局；其差异接近零。因此最合理的解释是：连续 NLL 捕获了轨迹之间的共享语义、错误模式、推理习惯或其他潜变量，而空白布局带来的 NLL 变化本身并不驱动错误传播。

## 透明的事后分解

该分解不改变绑定 gate：

- 480 对中，417 对的错误保留结果完全相同；
- 只有高原生版本保留错误：33 对；
- 只有低原生版本保留错误：30 对；
- 净差只有 3 对，与总体 `+0.625pp` 完全对应。

NLL 操纵幅度与 paired retention 差的剂量斜率为 `0.3995`，问题聚类 95% CI `[−0.1171, 0.9160]`。四个 NLL-gap 四分位的效果依次为 `+1.67pp`、`−1.67pp`、`−2.50pp`、`+5.00pp`，不呈稳定单调关系。

## 科学含义

这次结果淘汰了一个过于简单但很诱人的故事：

> “只要让错误轨迹更像接收模型平时会写的样子，错误就会更有感染力。”

至少在严格内容不变、只改自然空白布局的范围内，这个故事不成立。

仍然开放的更窄问题是：接收 NLL 是否代理了**语义级错误兼容性**，例如相同的错误分解、相同的捷径、相同的中间结论或相同的推理模板。要检验它，下一次干预必须改变语义表述而保持推理图和错误结论等价；这比空白干预更难识别，也更容易撞上 student-aligned rationale distillation、错误空间和 explanation transfer 的既有工作。

因此不得直接扩成跨模型大扫参。下一步应先完成一个理论与文献门槛：定义可验证的“同一错误计算图、不同语义实现”，并说明该因果量与已有的学生友好解释、错误相关性和答案锚定有何可分离的新预测。只有这个门槛通过，才值得生成语义重写版本。
