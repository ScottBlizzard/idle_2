# V2 carrier calibration

This is a capability-only calibration for a possible PolyPythias Stage 0 v2. The first
carrier placed the queried record first versus last and failed because one cell reached
only 66.4%; its files are preserved under `attempt1/`. A separate associativity carrier
is preserved under `associativity/`. Do not inspect any longitudinal curve.

The candidate is eligible for a separately frozen v2 only if both representations exceed
70% forced-choice accuracy on both the discovery and held-out template/item splits, and
the absolute within-split accuracy gap is no more than 10 percentage points.

Both attempted carriers are now closed. See `CALIBRATION_RESULTS.md`.
